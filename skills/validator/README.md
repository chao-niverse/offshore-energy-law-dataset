# validate_entries.py — 批量校验脚本

独立重算学生录入文件的全部规则(不依赖表内公式),输出逐条问题报告(xlsx)。

## 用法
```bash
python validate_entries.py 学生文件.xlsx --master 规范清单母表.xlsx -o 报告.xlsx
```
依赖:`pip install openpyxl`

批量运行(收齐全班文件后):
```bash
python batch_validate.py 收件文件夹 --master 规范清单母表.xlsx
```
逐份生成报告并输出 汇总.csv(每人条目数、错误、提醒、合规率)。

## 检查项(与 Schema「校验规则」列对应)
逐行:必填缺失 · 枚举取值 · 日期格式与状态-日期一致性 · 条目ID格式与唯一性 · 条文定位(条/款/项/段,政策文件(一)(二)编号按项)· 字数上限 · 行为模式内容与原文相似度(疑似复制)· 央地镜像字段规则(国家层必填配置/地方层必填类型)· 核实来源 AI 红线
跨行:同文件同定位且内容高度相似=重复(错误);同定位内容不同=一文多义拆分(提醒) · 关联条目存在性 · 位阶覆盖面 · 定位数字风格统一 · 版本号一致
交叉:与教师母表核对文件存在性、位阶、施行日期、效力状态

## 输出
- 摘要:条目数、错误/提醒数、条目合规率、覆盖位阶
- 问题清单:行号、条目ID、级别(错误=v2必改;提醒=须核实或说明)、检查项、详情

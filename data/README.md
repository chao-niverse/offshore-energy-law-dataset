# 数据说明

## seed/seed-data_v2.csv
教师制作的 30 条种子数据(第二轮全流程自测产出),覆盖法律与政策文件两个位阶、四份规范(节约能源法、深海海底区域资源勘探开发法、海洋能规模化利用指导意见、海上风电上网电价通知),含「惩罚性」类型、政策文件「项」编号定位、「一文多义拆分」等 Schema v0.5 新规则的实例。用途:校准学生工作量、验证 Schema、演示标注标准。编码 UTF-8(带 BOM,Excel 可直接打开)。字段定义见 [methods/schema.md](../methods/schema.md)。

本数据集经校验脚本 v1.1 全量校验(0 错误);其中一处施行日期经母表交叉核对修正(误将公布日填为施行日),修正过程记录于条目备注——这正是母表交叉核对机制的用途演示。

脱敏声明:录入人使用课程编号(S37),不含任何个人信息。条文内容以权威数据库核实为准;如与官方文本有出入,以官方文本为准并欢迎提 Issue。

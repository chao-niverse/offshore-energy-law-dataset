# 评分标准
#### 《数据处理与分析》· 广西大学法学院 窦超 制作 · v1.2

## 一、成绩构成

1. 课程最终成绩由平时成绩（40%）与期末成绩（60%）两部分组成。平时成绩与期末成绩单独计分。
2. 平时成绩由课程参与度（30%）、数据合规分（35%）和数据质量分（35%）三部分组成。课程参与度的评分内容包括：出勤、课堂参与、AI使用规范讨论贡献、数据组长工作、数据条目任务外挖掘工作等，由教师完成评分。数据合规分的评分内容是校验脚本对提交数据的逐条检查，按条目合规率计分，由机器完成评分。数据质量分的评分内容是规则五要素拆解的质量与概括准确性，由AI工具初步筛查可疑条目，由教师评定分数。
3. 期末成绩由智能体问答（60%）与智能体制作贡献度（40%）两部分组成。智能体问答由教师提问 → 回答溯源到本人条目 → 检验条目质量完成，全过程录音/录像/录频存档。智能体贡献度的评分内容包括数据条目v1→v2修订中的完成度、参与度，以及组长工作、双人项目差异讨论等附加分项。

## 二、程序保障
1. **兜底条款**。智能体系统不可用时，期末权重并入产物评分（数据条目合规分与质量分）。该规则保证成绩体系在AI工具失灵的情况下，凭借Excel数据就可以独立成立。
2. **申诉路径**。对数据合规分的申诉，可以凭校验报告逐条复算；对数据质量分与智能体问答分，凭留档记录向教师申诉复核。
3. **双人任务**。核心程度≥4星规范由两名学生独立完成。两人差异不影响各自得分，差异点进入课堂讨论，可获得额外加分。
4. **评分红线**。核实来源栏填写AI工具名或编造来源，该条计零分。行为模式栏整段复制原文，该条不计分。机器核对中发现互相抄袭等不诚信现象，课程考核不予通过。
